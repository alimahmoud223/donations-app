# Donations App

A backend REST API for managing donation campaigns, users, and donations.

## Features

- User Authentication & Authorization
- Create and Manage Donation Campaigns
- Make Donations
- Notifications System
- Protected Routes using JWT
- MongoDB Database Integration

## Tech Stack

- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- bcrypt
- dotenv
